# ai-dev-retro — AI 开发复盘教练

项目做完不等于学会了。这个 Skill 把"你边做边问 AI、AI 边答边补"的真实过程拆开，和高标准 AI Agent 工程师的完整工作流对照，让你看见自己缺了哪几步、哪些是 AI 替你做的决定、哪些概念还没建立。

## 核心方法：四色标记体系

| 标记 | 含义 |
|---|---|
| 🟢 | 你主动驱动——自己提出、想清楚、拍板的环节 |
| 🟡 | 靠问 AI 才推进——卡住了才知道怎么做 |
| 🔴 | AI 自动补丁——你从未提及，AI 自己加的决策 |
| ⚪ | 完全缺失——标准流程里有但项目中没出现过 |

## 四步复盘流程

1. **收集素材**：回顾对话时间线、项目产物清单、关键决策点
2. **对照基准**：逐项核对标准流程清单，标记四色
3. **识别盲区**：发现初学者典型盲区（没先想清楚就开干、技术选型盲从、没测试、没工程化等）
4. **输出报告**：结构化反馈 + 下次项目立刻能用的改进动作
